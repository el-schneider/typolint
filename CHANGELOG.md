## 0.1.0

- First release: lint and fix quotes, apostrophes, ellipses, dashes and spaces in UI copy, per locale, with quote data from Unicode CLDR 48.2. Plain strings with `{placeholders}` and ICU MessageFormat. CLI for YAML and JSON files with in-place `--fix`, a `typolint.json` config with house-style overrides and presets, and a Zod `superRefine` helper.
